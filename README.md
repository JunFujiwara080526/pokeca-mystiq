# Mystiq — 謎解き大会 回答・進行システム

ポケカ謎解き大会（pokeca-j-league.info）などの月1回開催を想定したWebシステムです。参加者はスマホで回答、管理者は進行・ヒント公開・受付管理をブラウザから行えます。問題文や画像は紙・スライドなどで別途用意し、システムでは「解答とヒント」だけを扱います。

## 画面一覧

| 画面 | 用途 |
| --- | --- |
| `index.html`（回答） | 参加登録・回答入力・ヒント表示・結果カード |
| `ranking.html`（ランキング） | 自動集計の順位表（約5秒更新） |
| `screen.html`（実況ボード） | **別会場のプロジェクター/モニター投影用**。順位表＋実況速報（約2.5秒更新） |
| `admin.html`（管理） | パスワード保護。ヒント公開・進行操作・設定編集・バックアップ |

---

## 🔒 管理画面のパスワードについて

管理画面（`admin.html`）は**パスワード認証で保護**されています。

- **初期パスワード（ローカル初回起動時）**：安全なランダム英数字16文字が自動生成され、`data/admin_password.txt` に保存され、起動ログにも表示されます
- **Renderで動かす場合**：環境変数 `ADMIN_PASSWORD` に指定した値がパスワードになります（Renderの管理画面からいつでも変更可）
- **パスワード変更**：管理画面右上の「🔑 パスワード変更」ボタンから変更できます（環境変数管理時はRender側で変更）
- **ログアウト**：右上の「🚪 ログアウト」でセッションを破棄できます

## 🚀 クラウド公開手順（Render ＋ Xserverドメイン）

独自ドメイン **`pokeca-j-league.info`** で世界中どこからでもアクセスできるようにする手順です（サーバー代は**完全無料**）。

### ステップ1：アプリ側の準備（完了済み ✅）
管理画面パスワード機能・Render用設定ファイル（`render.yaml` / `Procfile` / `requirements.txt` / `.gitignore`）は本リポジトリに実装済みです。

### ステップ2：Renderにアプリを配置

1. [GitHub](https://github.com/)（未登録なら無料登録）にログインし、この `outputs/mystiq` の中身を新しいリポジトリとしてプッシュします
2. [Render](https://render.com/) に無料登録（GitHub連携で一発ログイン）
3. 管理画面右上の **「New +」→「Web Service」** を選択
4. 作成したGitHubリポジトリを選択し、以下のように設定して **「Create Web Service」**：
   - **Name**: `pokeca-mystiq`（英数自由）
   - **Region**: Singapore または Oregon
   - **Language**: Python
   - **Build Command**: （空欄のままでOK）
   - **Start Command**: `python3 server.py`
   - **Instance Type**: Free（無料）
   - **Environment Variables**:
     - `PORT` → （自動注入されるので設定不要）
     - `HOST` → `0.0.0.0`
     - `ADMIN_PASSWORD` → あなたが決めた管理者パスワード（英数8文字以上）
5. デプロイが完了すると `https://〇〇.onrender.com` でアプリが開きます。この時点で `.../screen.html` を開けば実況画面も見られます。

> **💡 Render無料枠の注意点**：15分アクセスがないと一時休止し、次回アクセス時に約30〜50秒の起動待ちが発生します。**大会開始10分前に管理者が一度アクセスしておけば大会中は落ちません**（月額完全無料）。

### ステップ3：エックスサーバー側でドメインを紐づける

1. [Xserverドメインの会員パネル](https://secure.xserver.ne.jp/xapanel/login/xdomain/) にログイン
2. **「ドメイン管理」→ `pokeca-j-league.info` の「DNSレコード設定」** を開く
3. Render側で「Custom Domains」→ `pokeca-j-league.info` を追加すると、設定すべきDNS情報が表示されます
4. 表示された値（通常は CNAME レコードまたは A レコード）を、XserverドメインのDNSレコードにコピー＆ペーストして保存
5. 設定が反映されると（数分〜数時間）、`https://pokeca-j-league.info` でアクセスできるようになります。無料SSLもRenderが自動発行します

### ステップ4：別会場で映るかテスト

- **実況画面**：会場の端末（プロジェクター接続PCやiPad）で `https://pokeca-j-league.info/screen.html` を開いて全画面化
- **回答画面**：スマホから `https://pokeca-j-league.info` を開いてテスト回答
- **管理画面**：`https://pokeca-j-league.info/admin.html` で設定したパスワードでログインできることを確認

## 毎月の準備

1. 謎の問題を紙やスライドなどで別途用意します（システムへの問題文登録は不要）
2. 管理画面「解答・ヒント設定（JSON）」で各問の正解・ヒントなどを設定し保存
3. 参加者はスマホからニックネームで参加し、紙の謎を見ながら解答を入力
4. 運営は管理画面「ヒント管理」からヒントを随時公開
5. 必要に応じて受付停止や全体アナウンスを送信
6. 大会後は「データバックアップ」で記録を保存、次回用に「データリセット」を実行

## 設定例

```json
{
  "title": "ポケカ Jリーグ 謎解き大会",
  "stages": [
    {
      "id": 1,
      "name": "第1問",
      "answerNote": "ひらがなで入力",
      "answers": ["ピカチュウ"],
      "hints": ["黄色い身体のポケモンです", "電撃を使います"],
      "nearAnswers": [
        {"input": "ライチュウ", "message": "進化後ではなく..."}
      ]
    }
  ],
  "clearMessage": "全問クリア！おめでとう！"
}
```

- `id`: 重複しない整数。設定順に解答します
- `answers`: 正解の配列。全角/半角・ひらがな/カタカナ・英字大小・空白記号は自動正規化して判定
- `hints`: ヒント配列。保存後に管理画面から公開操作
- `nearAnswers`: 「惜しい！」メッセージ用

## 記録について

参加者・解答・進行状況は `data/mystiq.db` に保存されます。不正解も記録され連続入力制限（総当たり防止）に使われますが、回数は画面に表示しません。ブラウザ側に端末識別情報が保持されるため、別の端末では引き継がれません。

## 🎯 問題・ヒントの設定（問題ビルダー）

管理画面（`admin.html`）の「**問題と正解・ヒントの設定**」から、ボタン操作だけで完結します：

- **問題数を自由に増減**：「＋ 新しい問題を追加」「この問を削除」ボタンで問を好きなだけ増やせます（3問でも10問でも20問でもOK）
- **ストーリーは完全不要**：世界観や長文の登録枠はありません。問題文・画像は紙やスライド等で別途用意します
- **ヒント数は問ごとに自由**：「＋ ヒントを追加」で問ごとに0個・1個・5個など自由な数に設定可能
- **正解の複数登録**：1行に1つの正解を改行区切りで入力（ひらがな・英字などのバリエーションを吸収）
- **大会中のクイックヒント追記**：ヒント管理画面の各問にある「この問に新しいヒントを追記：[追加して即公開]」で、進行状況を見ながら**スマホから1行追記して即公開**できます
